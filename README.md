# naifmersal.github.io

Source of my personal website, built with [Quarto](https://quarto.org).

- **Edit:** `index.qmd` (homepage), `posts/<slug>/index.qmd` (posts).
- **Preview:** `quarto preview`
- **Publish:** push to `main`. GitHub Actions renders the site and deploys it
  to GitHub Pages (`.github/workflows/publish.yml`).

The theme files in `_ink/` are generated by the Ink brand kit; don't edit them
here. Site-specific styles go in `styles.css`.
